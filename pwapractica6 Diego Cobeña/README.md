# Heladería Polar

Sistema de gestión de una heladería. Proyecto final de Programación Web Avanzada (Ejercicio 37).

**Integrante:** Diego Cobeña

## Tecnologías

HTML, CSS, Bootstrap 5, JavaScript, PHP 8 (sin frameworks) y MySQL.

## Instalación

1. Copiar el proyecto en `htdocs` (XAMPP) o `www` (Laragon).
2. En phpMyAdmin crear la base de datos `heladeria` e importar `heladeria.sql`.
3. Abrir el proyecto en el navegador desde `http://localhost/`.
